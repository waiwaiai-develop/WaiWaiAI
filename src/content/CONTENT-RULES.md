# ブログ記事コンテンツルール

## 絶対ルール
1. **嘘を書かない** — 達成していない実績を「達成した」と書かない
2. **架空のデータを載せない** — 具体的な数字は実際のもののみ使用
3. **「〜できます」「〜が可能です」の表現を使う** — 「〜しました」は実績のあるもののみ
4. **月商や売上の具体額は非公開** — 倍率や傾向で表現
5. **エージェントの固有名詞は非公開** — 「総合窓口」「開発担当」等の役割名で記載
6. **スクレイピング等の倫理的にグレーな手法は記載しない** — 「データ連携」「API連携」「自動取得」等で表現

## トーン
- 非エンジニアが読んでもわかる平易な日本語
- 専門用語を使う場合は必ず簡単な説明を添える（例: RAG → 括弧不要、代わりに「自社データと連携したAI」と書く）
- 正直で率直。できないこと・課題も書く
- 売り込み臭くしない。役に立つ情報を出した上で、自然にサービスへ繋げる

## 構成（心理学的に読まれ・発注に繋がる構成）
1. **共感できる課題提示** — 読者の「あるある」から始める
2. **解決の方向性** — 「こうすればこうなる」を具体的に
3. **信頼の根拠** — 当社の取り組みや実績に触れる（嘘のない範囲で）
4. **中間CTA** — 記事の途中に自然な導線（blockquote等で「ご相談承ります」）
5. **行動のハードルを下げる** — 「初回無料」「30分のオンライン相談」「まずは〜から」
6. **記事末尾CTA** — PaymentLinkButton + 問い合わせ誘導

## SEO
- titleにキーワードを含める
- descriptionは120文字以内で要点を
- slugは英語・ハイフン区切り・キーワード入り
- h2を5個以内、h3は各h2に2個以内（読みやすさ重視）

## NG表現
- 「革命的」「画期的」「最先端」等の大げさな修飾語
- 「たった○○で」「驚きの」等の煽り表現
- 未達成の成果を断言する表現
- 他社を貶める比較
