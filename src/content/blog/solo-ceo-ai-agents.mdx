## 社員ゼロは戦略的選択

当社は代表1名＋AIエージェント群で運営。理由はシンプル：

- 固定費最小化 → 利益率最大化
- 意思決定が圧倒的に速い
- AIの進化速度を考えると、今は人よりAIインフラに投資すべき

## AIエージェント構成

役割ごとに専門AIエージェントを配置。

| 役割 | 主な業務 |
|------|---------|
| 総合窓口 | 経営判断サポート、タスク管理 |
| エンジニア | コーディング、コードレビュー |
| 戦略顧問 | 事業計画、価格設定、市場分析 |
| マーケター | SNS運用、コンテンツ作成 |
| デザイナー | UI/UX、ブランディング |

それぞれに**人格定義**と**長期記憶ファイル**を持たせ、セッションを跨いで一貫した判断が可能。

## セカンドブレイン: Obsidian

会社の全情報をObsidian Vaultに集約。MarkdownベースだからAIがそのまま読み書きできる。

```
CompanyBrain/
├── projects/      # 案件ノート
├── sop/           # 業務手順書
├── design/        # 設計方針
├── knowledge/     # ナレッジ
└── agents/        # AIエージェントデータ
    ├── shared/    # 共有記憶
    └── ...        # 各エージェントの記憶
```

## 1日の流れ

- **朝**: 前日の作業状態を読み込み → タスク確認
- **午前**: AIと開発（レビュー→修正ループ → git push → 自動デプロイ）
- **午後**: クライアントMTG + AIと経営壁打ち + SNS投稿
- **夕方**: 意思決定ログ・パターン集に記録 → 翌日への引き継ぎ
