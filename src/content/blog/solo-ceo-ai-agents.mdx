## これは実験の記録です

当社は代表1名＋AIエージェント群で会社運営を試みています。完成した仕組みの紹介ではなく、**現在進行形の実験記録**として読んでください。

## なぜ社員ゼロか

- 固定費を最小化したい
- 意思決定を速くしたい
- AIの進化速度を考えると、今は人よりAIインフラに投資したい

## やっていること

### AIエージェントの役割分担

役割ごとに専門のAIエージェントを設定し、それぞれに人格定義と長期記憶を持たせています。

| 役割 | 主な業務 |
|------|---------|
| 総合窓口 | 経営判断サポート、タスク管理 |
| エンジニア | コーディング、コードレビュー |
| 戦略顧問 | 事業計画、市場分析 |
| マーケター | SNS運用、コンテンツ作成 |
| デザイナー | UI/UX、ブランディング |

### Obsidianをセカンドブレインに

会社の全情報をObsidian Vaultに集約。MarkdownベースなのでAIがそのまま読み書きできます。

```
CompanyBrain/
├── projects/      # 案件ノート
├── sop/           # 業務手順書
├── design/        # 設計方針
├── knowledge/     # ナレッジ
└── agents/        # AIエージェントデータ
```

## うまくいっていること

- **開発速度**: Claude Codeとの協業で、1人でも複数案件を並行できている
- **知識の蓄積**: Obsidianに記録が溜まるほど、AIの出力精度が上がる
- **意思決定**: AIと壁打ちしてから判断することで、考慮漏れが減った

## まだできていないこと

- **自動収益源**: コンテンツ販売やSaaSはこれから
- **SNSの完全自動化**: 仕組みは作ったが運用はまだ手動が多い
- **AIの判断ミス**: チェックにはまだ人間の目が必要
- **信頼構築**: クライアントとの関係はAIだけでは作れない

## これからの方向性

- ストック型収益の仕組みづくり
- コンテンツ生成→投稿→分析のフル自動化
