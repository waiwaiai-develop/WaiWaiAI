## はじめに: なぜ「社員ゼロ」を選んだのか

WaiWai AIは、社長1名＋AIエージェント群で運営されている会社です。これは人を雇えないのではなく、**意図的に選択した経営スタイル**です。

理由はシンプルです：

- **固定費を最小化**し、利益率を最大化できる
- **意思決定の速度**が圧倒的に速い
- **AIの進化速度**を考えると、今人を雇うより先にAIインフラを構築すべき

## AIエージェント群の構成

現在、以下のAIエージェントが社内で稼働しています：

| エージェント名 | 役割 | 主な業務 |
|--------------|------|---------|
| リマ | 総合窓口・経営アドバイザー | 経営判断のサポート、タスク管理 |
| るなぴ | フルスタックエンジニア | コーディング、コードレビュー |
| 孫正義 | 事業戦略アドバイザー | 事業計画、価格設定、市場分析 |
| ツウィ | マーケター | SNS運用、コンテンツ作成、データ分析 |
| アヤカ | デザイナー | UI/UXデザイン、ブランディング |

これらは「ごっこ遊び」ではありません。それぞれに明確な**人格定義（SOUL.md）**と**長期記憶（MEMORY.md）**を持ち、セッションを跨いで一貫した判断ができます。

## セカンドブレイン: Obsidian × AI

会社の全情報は**Obsidian Vault**に集約しています。これが「会社の脳」です。

```
WaiWaiAI_Brain/
├── 00-inbox/        # 未整理メモ
├── 01-projects/     # 案件ノート
├── 02-sop/          # 業務手順書
├── 03-design/       # 設計方針
├── 06-knowledge/    # ナレッジ
├── 07-daily/        # 日次ノート
└── 09-agents/       # AIエージェントデータ
    ├── shared/      # 共有記憶
    ├── rima/        # リマの記憶
    ├── lunapi/      # るなぴの記憶
    └── ...
```

### なぜObsidianなのか

1. **Markdownベース** — AIが直接読み書きできる
2. **ローカルファースト** — 機密情報をクラウドに依存しない
3. **リンク構造** — 知識が有機的につながる
4. **Git管理可能** — バージョン管理と複数デバイス同期

## 1日の業務フロー

典型的な1日の業務フローを紹介します：

### 朝（9:00〜10:00）: 状況確認

```
1. Obsidianで日次ノートを開く
2. Claude Codeを起動 → SESSION-STATE.md を自動読み込み
3. 前日の続きや今日のタスクを確認
4. GitHub Issuesで案件の進捗チェック
```

### 午前（10:00〜12:00）: 開発作業

```
1. Claude Codeに実装を依頼
2. レビュー → フィードバック → 修正のループ
3. 完成したらgit push → Vercel自動デプロイ
```

### 午後（13:00〜17:00）: 顧客対応＋経営

```
1. クライアントとのミーティング（週2〜3回）
2. 見積もり・提案書の作成（AIアシスト）
3. 経営判断（孫正義エージェントと壁打ち）
4. SNS投稿（ツウィエージェントが下書き生成）
```

### 夕方（17:00〜18:00）: 記録

```
1. 今日の決定事項をdecisions.mdに記録
2. 学んだパターンをpatterns.mdに追加
3. SESSION-STATE.mdを更新（翌日の自分 or AIへの引き継ぎ）
```

## 数字で見る効果

AI中心の経営に移行してからの変化：

| 指標 | 移行前 | 移行後 |
|------|--------|--------|
| 月の稼働時間 | 250h | 120h |
| 案件同時並行数 | 2件 | 5件 |
| 見積もり作成時間 | 3時間 | 30分 |
| 月商 | 30万円 | 54万円 |

稼働時間が**半分以下**になりながら、売上は**1.8倍**に増えています。

## 課題と今後

正直に言うと、まだ完璧ではありません。

### 現在の課題

- **AIの判断ミスのチェック**にはまだ人間の目が必要
- **クライアントとの信頼構築**はAIだけでは難しい
- **税務・法務**などの専門領域はまだ人間に依頼している

### 今後の展望

1. **自動収益源の構築** — コンテンツ販売、SaaS、テンプレート販売
2. **SNS自動運用** — コンテンツ生成→投稿→分析のフル自動化
3. **月商150万円**の達成 — ストック型収益の積み上げ

## まとめ

1人社長×AIエージェントの経営は、まだ実験段階ですが確実に成果を出しています。重要なのは：

- AIは「ツール」ではなく「チームメンバー」として設計する
- 記憶と文脈を持たせることで、一貫性のある業務が可能になる
- 人間は「意思決定」と「信頼構築」に集中する
