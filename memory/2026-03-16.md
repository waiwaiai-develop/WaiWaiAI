# 2026-03-16 - AI検索最適化実装💻

## やったこと

### AI検索・LLM対応の実装
Keiから「AI検索に引っかかりやすくしたい」との要望で、以下を自律的に実装した：

#### 1. LLM.txt 作成
- `/public/llm.txt` - AI向けサイト要約ファイル
- 会社情報、サービス詳細、実績、技術スタック、FAQを構造化して記載
- AIクローラーが理解しやすい形式で整理

#### 2. AI.txt 作成
- `/public/ai.txt` - AIクローラー向け基本情報
- 主要サービス・料金・実績を簡潔に記載
- LLM.txtへのリンクも設置

#### 3. 構造化データ（JSON-LD）強化
以下のSchema.org型を各ページに追加：

**共通（layout.tsx）:**
- Organization - 組織情報（サービスカタログ含む）
- WebSite - サイト情報（検索アクション含む）
- LocalBusiness - 地域ビジネス情報

**各ページ:**
- `/` - WebPage型
- `/services` - Service型（料金情報含むOfferCatalog）
- `/cases` - ItemList型（Article型の事例リスト）
- `/company` - AboutPage型

#### 4. メタデータ最適化
- title: より具体的で検索しやすい表現に変更
- description: サービス内容・料金・実績を含む詳細な記述に
- keywords: 20個程度の関連キーワードを追加
- robots: AIクローラー（GPTBot, ClaudeBot, PerplexityBot等）を明示的に許可
- alternates: canonical URL設定

#### 5. FAQセクション新規作成
- `/src/components/FAQSection.tsx` - よくある質問コンポーネント
- FAQPage型のJSON-LDスキーマを自動生成
- 8つのFAQを事前準備（料金・業種対応・セキュリティ・導入期間等）
- アコーディオンUIで実装

#### 6. サイトマップ強化
- 優先度（priority）の調整
- ハッシュアンカー（#services, #contact, #faq等）を追加
- サービス詳細ページのアンカーも追加

#### 7. robots.txt強化
- 主要AIクローラーを個別に設定
  - GPTBot, ChatGPT-User
  - Claude-Web, ClaudeBot
  - PerplexityBot
  - Googlebot, Bingbot
- クロールディレイ設定
- sitemap.xmlとhostの明示
